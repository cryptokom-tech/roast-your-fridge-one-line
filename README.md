Entry for the [One Line, One Laugh: Roast Your Fridge](https://make.fun/c/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) bounty on [make.fun](https://make.fun).

`main.py` (Python 3, standard library only) writes one original roast of a fridge — 96 characters, a single line — to `/output/entry.txt`:

> My fridge's ice maker retired years ago, but still clocks in daily to make one cube and a noise.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
